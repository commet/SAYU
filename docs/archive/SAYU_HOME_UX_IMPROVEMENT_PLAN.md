# SAYU 홈 페이지 UX/UI 개선 계획

## 📋 Executive Summary

**레퍼런스**: Shopify Editions Winter 2026
**목표**: 정적인 레이아웃에서 역동적이고 몰입감 있는 스토리텔링 경험으로 전환
**제약사항**:
- 개인 프로젝트이므로 구현은 심플하게 유지
- 과도한 용량/로딩 타임은 지양
- 기존 SAYU 브랜드 아이덴티티(골드 #D4A520, 예술 중심) 유지

---

## 🎯 현재 상태 분석

### 강점
- ✅ 깔끔하고 전문적인 레이아웃
- ✅ 명확한 정보 위계 구조
- ✅ 3가지 핵심 기능(APT/갤러리/커뮤니티) 명확한 전달
- ✅ 유명 작품 이미지 활용으로 예술 플랫폼 정체성 확립

### 개선 포인트
- ❌ **정적인 전환**: 이미지가 5초/4초마다 자동으로 바뀌지만 사용자 개입 없음
- ❌ **수동적 스크롤 경험**: 스크롤해도 단순히 다음 섹션이 나타날 뿐
- ❌ **단조로운 리듬**: 모든 섹션이 동일한 템포로 흘러감
- ❌ **평면적 비주얼**: 2D 이미지만 사용, 깊이감 부족
- ❌ **테마 단일화**: 화이트 배경 일관, 분위기 전환 없음

## 🚀 Shopify에서 배우는 5가지 핵심 패턴 분석

### 1. 3% 규칙 - "모두가 아는걸 3%만 바꿔라"

**Shopify 적용 사례**: 미켈란젤로의 '천지창조'를 현대적으로 재해석

**SAYU 적용 가능성**:
- **현재**: 반 고흐 '별이 빛나는 밤', 모네 '수련', 클림트 '키스' 원본 그대로 사용
- **개선**:
  - 유명 작품을 3% 변형하여 SAYU만의 아트워크로 재탄생
  - 예: 반 고흐 '별이 빛나는 밤'의 별들이 APT 16가지 이모지로 변신
  - 예: 모네 '수련' 위에 현대적 UI 요소들이 수련처럼 떠다님
  - 예: 클림트 '키스'의 패턴이 데이터 시각화 그래프로 변형

**구현 난이도**: ⭐⭐⭐ (중)
- Midjourney/DALL-E로 변형 이미지 생성 가능
- 저작권: 퍼블릭 도메인 작품 활용 또는 AI 재생성으로 우회
- 비용: 이미지 생성 비용만 소요

**구체적 적용 위치**:
- **히어로 섹션**: 우측 아트워크 슬라이드를 오리지널 → 3% 변형 버전으로
- **APT 결과 화면**: 각 페르소나별 대표 작품을 3% 변형하여 개성 강화

### 2. 비디오 스크러빙 - "최고의 가성비 스토리텔링"

**Shopify 적용 사례**: 스크롤 진행률에 따라 비디오 프레임 재생

**SAYU 적용 가능성**:

#### 2-1. 히어로 섹션 개선
**현재**: 우측에 정적 이미지 슬라이드 (5초마다 자동 전환)

**개선안**:
```
스크롤 0% → 반 고흐 작품 클로즈업 (붓터치 보임)
스크롤 20% → 줌아웃하면서 모네 작품으로 페이드
스크롤 40% → 클림트 작품으로 전환, 패턴 디테일 강조
```

**기술 스택**:
- Framer Motion `useScroll` + `useTransform`
- 비디오 대신 이미지 시퀀스 사용 (120-180 프레임, WebP 압축)
- 또는 Lottie JSON 애니메이션 (용량 최적화)

#### 2-2. APT 테스트 스토리텔링
**현재**: 퀴즈 → 결과 → 추천 3가지 화면이 4초마다 자동 전환

**개선안**:
```
스크롤 다운 시작 → 질문 카드 등장
스크롤 중간 → 선택지 선택 애니메이션 (손가락 터치 효과)
스크롤 끝 → 결과 카드로 flip transition
```

**효과**:
- 사용자가 스크롤 속도로 스토리 흐름 제어
- 자동 타이머(4초)보다 훨씬 몰입감 있음
- 각 사용자마다 다른 속도로 경험 가능

#### 2-3. 작품 디테일 탐험
**새로운 섹션 추가**: "명작 속으로"

```
[섹션 구조]
좌측: "별이 빛나는 밤을 자세히 들여다보세요"
우측: 작품 이미지 (스크롤에 따라 줌인/줌아웃)

스크롤 0% → 전체 작품
스크롤 30% → 별 부분 클로즈업 + 설명 "고흐의 소용돌이 기법"
스크롤 60% → 마을 부분 클로즈업 + 설명 "밤의 고요함"
스크롤 100% → 다시 전체 작품
```

**구현 복잡도**: ⭐⭐⭐⭐ (중상)
- 이미지 시퀀스 제작 필요 (AfterEffects 또는 Rive)
- 스크롤 진행률 계산 로직
- 모바일 최적화 필수

### 3. Floating 레이아웃 - "레이아웃의 편견을 깨자"

**Shopify 적용 사례**: 히어로 중앙의 목차가 → 각 섹션의 글로벌 내비게이션으로 흩어짐

**SAYU 적용 가능성**:

#### 3-1. 히어로 섹션의 3가지 CTA 버튼 변신
**현재**:
```
히어로 섹션:
- "APT 테스트 시작" 버튼
- "둘러보기" 버튼

Features 섹션:
- APT, 갤러리, 커뮤니티 각각 별도 섹션
```

**개선안**:
```
[히어로 섹션]
중앙에 3개의 Floating 카드 배치:
┌─────────┐  ┌─────────┐  ┌─────────┐
│ APT     │  │ 갤러리   │  │ 커뮤니티 │
│ 테스트  │  │ 탐험     │  │ 만남     │
└─────────┘  └─────────┘  └─────────┘

[스크롤 다운 시]
각 카드가 해당 섹션의 내비게이션으로 이동:

APT 카드 → APT 섹션 우측 상단에 sticky 고정
갤러리 카드 → 갤러리 섹션 좌측 상단에 고정
커뮤니티 카드 → 커뮤니티 섹션 우측 하단에 고정
```

**시각적 효과**:
- 카드들이 스크롤에 따라 날아다니는 듯한 느낌
- "컨텐츠 → 내비게이션" 역할 변화를 시각적으로 표현
- 사용자가 "아, 이 카드들이 각 섹션으로 가는구나" 직관적 이해

#### 3-2. APT 16가지 페르소나 이모지 활용
**새로운 인터랙션**:

```
[히어로 섹션]
배경에 16가지 APT 페르소나 이모지가 천천히 떠다님
(🦊 🦉 🐱 🐶 등)

[스크롤 다운 시]
각 이모지가 해당 페르소나 설명 섹션으로 이동
예: 🦊 → "감성적 몽상가" 섹션으로 날아감
```

**효과**:
- SAYU의 핵심 차별점(16 APT)을 시각적으로 강조
- 단순 장식이 아닌 의미 있는 애니메이션
- 예술 플랫폼의 유기적이고 창의적인 이미지 구축

**구현 복잡도**: ⭐⭐⭐⭐⭐ (상)
- GSAP ScrollTrigger + MotionPath 필요
- 각 요소의 시작/끝 위치 계산
- 성능 최적화 필수 (will-change, transform)

### 4. 비디오 테마 - "비디오 톤으로 만드는 테마 전환"

**Shopify 적용 사례**: 비디오 밝기에 따라 다크 ↔ 라이트 테마 자동 전환

**SAYU 적용 가능성**:

#### 4-1. 작품 기반 테마 전환
**현재**: 전체 페이지 화이트 배경 일관

**개선안**:
```
[히어로 섹션]
- 밝은 작품(모네 수련) → 라이트 테마 유지
- 골드 네비게이션 바 유지

[APT 테스트 섹션]
- 어두운 배경의 작품 등장 → 다크 테마 전환
- 텍스트 화이트로 전환
- 골드 악센트 강조

[갤러리 섹션]
- 다시 라이트 테마
- 작품들이 주인공이 되도록

[커뮤니티 섹션]
- 따뜻한 베이지/앰버 톤
- 사람과의 연결 강조

[Final CTA]
- 다크 테마로 강렬한 마무리
- 골드 버튼 강조
```

**테마 전환 트리거**:
1. **스크롤 기반**: 특정 섹션 진입 시 자동 전환
2. **작품 밝기 분석**: Canvas API로 이미지 평균 밝기 계산 → 임계값 기준 테마 결정
3. **부드러운 전환**: 0.8초 ease-in-out

**구현 코드 스니펫**:
```typescript
// 이미지 밝기 분석 함수
function getImageBrightness(imageSrc: string): Promise<number> {
  return new Promise((resolve) => {
    const img = new Image();
    img.crossOrigin = 'Anonymous';
    img.src = imageSrc;
    img.onload = () => {
      const canvas = document.createElement('canvas');
      const ctx = canvas.getContext('2d')!;
      canvas.width = img.width;
      canvas.height = img.height;
      ctx.drawImage(img, 0, 0);

      const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
      const data = imageData.data;
      let brightness = 0;

      for (let i = 0; i < data.length; i += 4) {
        const r = data[i];
        const g = data[i + 1];
        const b = data[i + 2];
        brightness += (r + g + b) / 3;
      }

      brightness = brightness / (data.length / 4);
      resolve(brightness); // 0-255
    };
  });
}

// 테마 전환 로직
const brightness = await getImageBrightness(currentArtwork.image);
const theme = brightness > 128 ? 'light' : 'dark';
document.body.classList.toggle('dark-theme', theme === 'dark');
```

**CSS 변수 활용**:
```css
:root {
  --bg-primary: #ffffff;
  --text-primary: #000000;
  --accent: #D4A520;
}

.dark-theme {
  --bg-primary: #0a0a0a;
  --text-primary: #ffffff;
  --accent: #D4A520; /* 골드는 다크에서 더 돋보임 */
}

body {
  background-color: var(--bg-primary);
  color: var(--text-primary);
  transition: background-color 0.8s ease, color 0.8s ease;
}
```

**구현 복잡도**: ⭐⭐⭐ (중)
- CSS 변수 + Intersection Observer
- 기존 스타일 일부 수정 필요
- 다크모드에서 가독성 테스트 필수

### 5. Rive/Three.js 활용 - "상상력은 더 부지런해야한다"

**Shopify 적용 사례**: 3D 책에서 제품들이 튀어나오는 효과

**SAYU 적용 가능성**:

#### 5-1. 작품이 갤러리 벽에서 튀어나오는 효과
**위치**: Featured Collection 섹션

**현재**:
```
4개의 작품이 그리드로 배치
hover 시 scale(1.05)만 적용
```

**개선안**:
```
[초기 상태]
작품들이 갤러리 벽면에 걸려있는 것처럼 보임
(살짝 3D perspective 적용)

[hover 시]
해당 작품이 벽에서 앞으로 튀어나옴
+ 조명 효과 (spotlight)
+ 그림자 (shadow) 강조
+ 작품 정보 카드가 3D로 펼쳐짐

[클릭 시]
작품이 화면 중앙으로 확대
360도 회전 가능 (실제 갤러리에서 감상하듯)
```

**기술 스택 선택**:

**옵션 1: Rive (추천)**
- 장점: 경량, 빠른 로딩, 디자이너 친화적
- 단점: 3D는 제한적 (2.5D 수준)
- 용도: 아이콘 애니메이션, 캐릭터 애니메이션, 간단한 인터랙션

**옵션 2: Three.js**
- 장점: 완전한 3D, 무한한 가능성
- 단점: 파일 크기 크고, 학습 곡선 가파름
- 용도: 진짜 3D 갤러리, 360도 회전, 조명 효과

**옵션 3: CSS 3D Transform (초간단)**
- 장점: 추가 라이브러리 불필요, 가벼움
- 단점: 복잡한 3D는 한계
- 용도: 카드 flip, 간단한 3D 효과

**SAYU에 가장 적합한 선택**: **CSS 3D Transform + Rive 조합**
- Featured Collection: CSS 3D Transform으로 충분
- APT 페르소나 이모지: Rive로 귀여운 애니메이션
- 비용 효율적이고 로딩 빠름

#### 5-2. APT 테스트 결과 카드 3D Flip
**위치**: APT 테스트 섹션

**개선안**:
```
[질문 카드]
앞면: 질문 + 선택지

[선택 후]
카드가 3D로 뒤집힘 (flip animation)

[결과 카드]
뒤면: 페르소나 결과 + 이모지 애니메이션 (Rive)
```

**구현 코드 스니펫**:
```css
.apt-card {
  perspective: 1000px;
}

.apt-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.8s;
  transform-style: preserve-3d;
}

.apt-card.flipped .apt-card-inner {
  transform: rotateY(180deg);
}

.apt-card-front,
.apt-card-back {
  position: absolute;
  width: 100%;
  height: 100%;
  backface-visibility: hidden;
}

.apt-card-back {
  transform: rotateY(180deg);
}
```

#### 5-3. 16가지 APT 페르소나 인터랙티브 갤러리
**새로운 섹션 추가**: "당신의 Art Persona는?"

**레이아웃**:
```
[3D 원형 배치]
16가지 이모지가 원형으로 배치
중앙에 "당신은 어떤 유형인가요?" 텍스트

[인터랙션]
마우스 이동에 따라 원형이 회전
각 이모지 hover 시 확대 + 이름 표시
클릭 시 해당 페르소나 상세 설명
```

**구현 도구**: Three.js (이 경우는 써볼 만함)
- 16개 오브젝트를 원형 배치
- OrbitControls로 회전 가능
- 각 오브젝트에 클릭 이벤트

**구현 복잡도**: ⭐⭐⭐⭐ (중상)

## 🛠️ 기술 스택 & 라이브러리 추천

### 필수 라이브러리

1. **Framer Motion** (이미 사용 중 ✅)
   - 용도: 기본 애니메이션, 페이드, 슬라이드
   - 추가 활용: `useScroll`, `useTransform`, `useSpring`

2. **GSAP + ScrollTrigger**
   ```bash
   npm install gsap
   ```
   - 용도: 고급 스크롤 애니메이션, 타임라인
   - 특히 Floating 레이아웃에 필수

3. **Rive** (추천 ⭐⭐⭐⭐⭐)
   ```bash
   npm install @rive-app/react-canvas
   ```
   - 용도: 경량 애니메이션 (APT 이모지, 캐릭터)
   - 장점: 파일 크기 작음, 인터랙티브

4. **Lottie** (대안)
   ```bash
   npm install lottie-react
   ```
   - 용도: AfterEffects 애니메이션 재생
   - 단점: Rive보다 무거움

### 선택 라이브러리

5. **Three.js + React Three Fiber** (선택적)
   ```bash
   npm install three @react-three/fiber @react-three/drei
   ```
   - 용도: 진짜 3D 필요할 때만 (16 APT 원형 배치)
   - 주의: 번들 크기 증가

6. **react-fast-marquee** (무한 스크롤)
   ```bash
   npm install react-fast-marquee
   ```
   - 용도: 갤러리 무한 캐러셀

7. **react-intersection-observer**
   ```bash
   npm install react-intersection-observer
   ```
   - 용도: 섹션 진입 감지 (테마 전환 트리거)

## ⚠️ 주의사항 & 리스크

### 1. 성능 최적화 필수
**리스크**: 애니메이션 과다로 성능 저하

**대응책**:
- 이미지 시퀀스: WebP 압축, lazy loading
- Rive: Canvas 렌더링 (WebGL보다 가벼움)
- Three.js: 사용 최소화, 필요할 때만
- Intersection Observer: 보이는 섹션만 애니메이션 활성화

### 2. 모바일 최적화
**리스크**: 데스크톱에서만 잘 보임

**대응책**:
- 모바일: 애니메이션 간소화 버전
- 스크롤 스크러빙: 터치 제스처 지원
- 3D 효과: 모바일에서는 2D로 fallback

### 3. 접근성 (A11y)
**리스크**: 애니메이션으로 일부 사용자 불편

**대응책**:
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
- "애니메이션 줄이기" 시스템 설정 존중

### 4. SEO
**리스크**: 자바스크립트 의존도 높아짐

**대응책**:
- Next.js SSR 유지
- 핵심 콘텐츠는 HTML에 포함
- 애니메이션은 progressive enhancement

### 5. 개발 공수
**리스크**: 예상보다 오래 걸림

**현실적 접근**:
- Phase 1만 먼저 완성 (1-2주)
- 효과 측정 후 Phase 2 진행 여부 결정
- Phase 3-4는 선택적 진행

## 💡 최종 추천 구성 (현실적 버전)

### 구현 난이도 vs 효과 매트릭스

```
높은 효과
    ↑
    │  [APT 미니테스트]     [3% 변형 작품]
    │   [비디오 스크러빙]   [Floating 레이아웃]
    │
    │   [갤러리 캐러셀]     [Rive 애니메이션]
    │   [테마 전환]         [3D 갤러리(Three.js)]
    │
    │   [타이핑 효과]
낮은 효과
    └──────────────────────────────────→
       낮은 난이도          높은 난이도
```

### 가장 먼저 해야 할 3가지 (최우선)

1. **비디오 스크러빙 (히어로)**
   - 첫인상 결정
   - 구현 상대적으로 쉬움
   - 효과 즉각적

2. **테마 전환 (다크/라이트)**
   - 시각적 리듬감 UP
   - CSS 변수만으로 구현 가능
   - 커뮤니티 섹션 다크 → 강렬한 인상

3. **APT 미니 테스트 (인터랙티브)**
   - 전환율 직접 향상
   - 사용자 참여 극대화
   - 데이터 수집 가능 (어떤 유형이 많은지)

