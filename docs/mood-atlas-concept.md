# Mood Atlas - 무드 아틀라스

> **"나만의 감정 지도 그리기"**
> 매일 감정을 기록하고, AI가 추천하는 작품을 감상하며, 예술 세계를 탐험하는 SAYU의 일일 도파민 기능

---

## 🎯 핵심 컨셉

### 개념
- **미술 × 감정 × 기억의 교차점**
- 매일 오늘의 감정을 "색"으로 선택
- AI가 그 감정에 맞는 작품 3개 추천
- 하나를 선택하고 간단한 메모 작성
- 예술 세계 지도에서 1타일 색칠
- 7개 대륙을 탐험하며 180일 완주 목표

### 왜 "Atlas"인가?
- **Atlas = 지도책**, 세계를 담은 책
- 감정의 세계를 하나씩 기록하는 나만의 지도책
- 탐험/발견/수집의 느낌
- 세련되고 예술적인 네이밍

### SAYU 철학과의 연결
- ✅ 다층적 감정 모델 (복합 감정, 강도 시스템)
- ✅ 개인화된 예술 경험 (AI 맞춤 추천)
- ✅ 의미있는 연결 (감정 → 예술 → 기억)
- ✅ 사용자 주도 여정 (지역 선택, 분기)
- ✅ **능동적 상호작용** (작품 터치, 선택, 태그)
- ✅ **나만의 창조물** (대륙별 캐릭터 생성)

## 🎨 감정 시스템: 6색 팔레트

### 기본 원리
**색상 = 감정의 직관적 표현**
- 심리학적 색상 연상 활용
- 학술적 분류가 아닌 "예술 감상 시 느끼는 감정"에 집중

### 6가지 색상 감정

#### 🔵 파랑 (Blue) - 사색과 평온
```
대표 감정: 평온, 차분, 고요, 사색적인, 그리운, 잔잔한
강도별:
- 연한 파랑 (10-30%): 가벼운 평화, 온화함
- 중간 파랑 (40-60%): 차분한 사색, 고요한 그리움
- 진한 파랑 (70-90%): 깊은 우수, 강렬한 그리움

연결 미술: 인상주의, 북유럽 풍경화, 청색시대 피카소
```

#### 🔴 빨강 (Red) - 열정과 에너지
```
대표 감정: 열정, 흥분, 활기, 설레는, 강렬한, 뜨거운
강도별:
- 연한 빨강 (10-30%): 은은한 설렘, 따뜻함
- 중간 빨강 (40-60%): 활기찬 열정, 에너지
- 진한 빨강 (70-90%): 강렬한 흥분, 폭발적 감정

연결 미술: 표현주의, 팝아트, 포비즘, 액션 페인팅
```

#### 🟡 노랑 (Yellow) - 희망과 따뜻함
```
대표 감정: 희망, 기쁨, 따뜻함, 밝은, 감사한, 경쾌한
강도별:
- 연한 노랑 (10-30%): 은은한 기쁨, 부드러운 빛
- 중간 노랑 (40-60%): 따뜻한 희망, 온기
- 진한 노랑 (70-90%): 눈부신 환희, 강렬한 감사

연결 미술: 후기인상주의, 반 고흐, 황금기 클림트
```

#### 🟣 보라 (Purple) - 신비와 경이
```
대표 감정: 신비, 몽환, 경이, 초현실적, 황홀한, 신성한
강도별:
- 연한 보라 (10-30%): 은은한 신비, 부드러운 꿈
- 중간 보라 (40-60%): 몽환적 분위기, 경이로움
- 진한 보라 (70-90%): 강렬한 신비, 황홀경

연결 미술: 상징주의, 초현실주의, 아르누보, 신비주의
```

#### 🟢 초록 (Green) - 생동과 조화
```
대표 감정: 생동, 평화, 신선, 조화로운, 안정적, 자연스러운
강도별:
- 연한 초록 (10-30%): 부드러운 평화, 온화한 조화
- 중간 초록 (40-60%): 생동하는 자연, 균형
- 진한 초록 (70-90%): 강렬한 생명력, 풍요로움

연결 미술: 자연주의, 풍경화, 인상주의, 낭만주의
```

#### ⚫ 회색 (Gray) - 고독과 공허
```
대표 감정: 쓸쓸, 우울, 무기력, 공허한, 고독한, 침잠
강도별:
- 연한 회색 (10-30%): 잔잔한 쓸쓸함, 고요한 무
- 중간 회색 (40-60%): 우울한 고독, 공허함
- 진한 회색 (70-90%): 깊은 침잠, 강렬한 무기력

연결 미술: 미니멀리즘, 입체주의, 모더니즘, 다다이즘
```

### 복합 감정 (Advanced)

**7일 이상 사용자에게 해금**

```
두 가지 색 조합 가능:

🔵 + 🟡 = 🟢 희망과 평온이 섞인 감정
🔴 + ⚫ = 💔 열정 속의 공허함
🟣 + 🔵 = 💙 신비로운 그리움
🔴 + 🟡 = 🧡 열정적인 기쁨
🟢 + 🟣 = 💚 신비로운 조화
⚫ + 🔵 = 🖤 우울한 사색

30일 이상: 3가지 색 조합 가능
```

## 🌟 캐릭터 생성 시스템 (NEW!)

### 핵심 개념

**"나만의 창조물"** - 수동적 감상을 넘어 능동적 창조로

```
대륙 완료 = 캐릭터 탄생

사용자의 상호작용 → 고유한 캐릭터 생성
공간 + 시간 + 인물 조합
```

### 상호작용 시스템

**작품 감상 시 능동적 참여:**

```
1️⃣ 비주얼 터치
   - 작품의 특정 부분 터치
   - "어떤 부분이 좋으세요?"

2️⃣ 색감 선택
   - 그림 속 색상 중 끌리는 색
   - "어떤 색이 마음에 드나요?"

3️⃣ 구도/형태 선택
   - 소용돌이, 대칭, 역동성 등

4️⃣ 인물/대상 선택
   - 작품 속 등장 인물/사물

5️⃣ 이야기/일화 선택
   - 작품 관련 정보 중 인상적인 것
```

### 캐릭터 구성

**대륙 완료 시 생성 = 공간 + 시간 + 인물**

```
🌊 인상주의 해안 완료 예시:

분석:
- 물 터치 12회, 하늘 8회
- 파란색 15회 선택
- 모네 작품 10회 감상
- "평온한" 태그 27회

↓

생성된 캐릭터:
🌊 수련의 정령
공간: 고요한 연못
시간: 새벽의 안개
인물: 수련 위를 떠다니는 투명한 정령

"당신이 사랑한 모네의 평온함이
 새로운 생명으로 깨어났습니다"
```

**캐릭터 타입:**
- 🎨 예술가 환생 (반 고흐, 모네, 달리 등)
- 🦊 신비로운 동물 (여우, 올빼미, 고양이)
- 👤 가상의 인물 (별을 좇는 소녀)
- 🌟 추상적 존재 (빛의 정령)

### 캐릭터 활용

**1. 프로필 대표 캐릭터**
```
내 프로필:
🌊 수련의 정령 (대표)
🌌 별을 그리는 반 고흐
🎨 네온 고양이

7개 대륙 = 최대 7개 캐릭터
```

**2. 캐릭터와의 상호작용**
```
[아침에 앱 열면]
🌊 수련의 정령:
"좋은 아침! 오늘은 어떤 색의
 감정을 느끼고 있어?"

[감정 기록 후]
"파란 감정이구나. 이 작품을
 추천해줄게!"
```

**3. 소셜 연결**
```
캐릭터 광장:
- 다른 사용자의 캐릭터 보기
- 같은 캐릭터 타입 찾기
- 캐릭터 간 대화/교류
- 협력 미션
```

**4. 성장 시스템**
```
Level 1: 탄생 (대륙 완료)
Level 2: 기억 축적 (+10회 감상)
Level 3: 깊은 유대 (+30일)
Level 4: 동반자 (전체 완주)
```

### mood_atlas_entries (감정 기록)

```sql
CREATE TABLE mood_atlas_entries (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,

  -- 감정 데이터
  emotion_color VARCHAR(20) NOT NULL, -- 'blue', 'red', 'yellow', 'purple', 'green', 'gray'
  emotion_intensity INT CHECK (emotion_intensity >= 0 AND emotion_intensity <= 100),
  emotion_label TEXT, -- "연한 파랑", "진한 빨강"

  -- 복합 감정 (고급)
  is_complex BOOLEAN DEFAULT false,
  color_secondary VARCHAR(20), -- 두 번째 색상

  -- AI 추천 작품
  recommended_artworks JSONB, -- [{ artworkId, title, artist, reason, expectedFeeling }]
  selected_artwork_id TEXT NOT NULL,
  selected_artwork_data JSONB, -- 작품 전체 정보 스냅샷

  -- 사용자 메모
  user_memo TEXT,

  -- 위치 정보 (어느 대륙)
  region VARCHAR(50) NOT NULL, -- 'renaissance', 'impressionist', 'expressionist', etc.
  tile_number INT, -- 해당 지역 내 타일 번호

  -- 메타
  created_at TIMESTAMP DEFAULT NOW(),
  date DATE NOT NULL,

  UNIQUE(user_id, date) -- 하루 1회만 기록
);

-- 인덱스
CREATE INDEX idx_mood_atlas_user_date ON mood_atlas_entries(user_id, date DESC);
CREATE INDEX idx_mood_atlas_region ON mood_atlas_entries(region);
```
