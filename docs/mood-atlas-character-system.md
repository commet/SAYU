# Mood Atlas - 캐릭터 생성 시스템

> **"나만의 창조물과 함께하는 예술 여정"**
> 능동적 상호작용을 통해 나만의 캐릭터를 창조하고, 그들과 함께 성장하는 시스템

---

## 🎯 핵심 철학

### SAYU의 핵심 가치 반영

**기존 문제점:**
- 수동적 감상: 그림을 보고, 정보를 읽고, 끝
- 일시적 경험: 기록은 남지만 특별한 결과물이 없음
- 개인화 부족: AI 추천은 있지만 나만의 것이 아님

**새로운 접근:**
- ✅ **능동적 참여**: 그림의 부분을 터치하고 선택하며 상호작용
- ✅ **나만의 창조**: 내 경험과 선택으로 고유한 캐릭터 생성
- ✅ **깊은 개인화**: 내 취향과 기억이 반영된 유일무이한 결과물
- ✅ **지속적 관계**: 생성된 캐릭터와 함께하는 여정
- ✅ **소셜 연결**: 내 캐릭터로 다른 사용자와 의미있는 연결

### 핵심 키워드

```
개인화 | 나만의 | 남들과는 다른 | 특별한
나를 알아줌 | 나를 기억해줌 | 피드백 | 상호작용 | 능동적
```

## 🎨 상호작용 시스템: Art Pulse 진화

### 개념

기존 **Art Pulse**의 진화형:
- 단순 하트 터치 → **다층적 상호작용**
- 일회성 반응 → **누적되는 기억**
- 감상 기록 → **창조의 재료**

### 상호작용 유형

#### 1️⃣ 비주얼 터치 (Visual Touch)

**그림의 특정 부분 터치하기**

```
작품: 반 고흐 "별이 빛나는 밤"

[작품 이미지]

✨ 어떤 부분이 마음에 드나요?
   여러 곳을 터치해보세요!

사용자 터치 → 누적 기록:
- 소용돌이치는 하늘 (★★★)
- 노란 별들 (★★★★)
- 어두운 사이프러스 나무 (★)
- 평온한 마을 (★★)
```

**수집 데이터:**
```javascript
{
  artworkId: "starry-night",
  visualPreferences: {
    "swirling-sky": { touches: 3, timestamp: [...] },
    "yellow-stars": { touches: 4, timestamp: [...] },
    "cypress-tree": { touches: 1, timestamp: [...] },
    "peaceful-village": { touches: 2, timestamp: [...] }
  },
  dominantInterest: "dynamic-movement" // AI 분석
}
```

#### 2️⃣ 색감 선택 (Color Preference)

**그림 속 색상 중 끌리는 색 선택**

```
이 작품에서 어떤 색감이 좋으세요?

[작품 이미지]

🎨 색상 팔레트:
  [진한 파랑] [노란색] [청록색]
  [검은색]   [흰색]

→ 사용자 선택: 진한 파랑, 노란색

💬 "강렬한 대비를 좋아하시는군요!"
```

**수집 데이터:**
```javascript
{
  colorPreferences: {
    "deep-blue": 15,    // 15번 선택
    "yellow": 12,
    "cyan": 8,
    "black": 3
  },
  colorHarmony: "contrast-lover" // 또는 "harmony-seeker"
}
```

#### 3️⃣ 구도/형태 선택 (Composition)

**구도나 형태 요소 선택**

```
이 작품의 어떤 요소가 인상적이었나요?

□ 소용돌이치는 움직임
□ 수평적 안정감
□ 대각선 역동성
□ 대칭적 균형
□ 불규칙한 리듬

→ 사용자 선택: 소용돌이치는 움직임, 불규칙한 리듬

💬 "역동적이고 자유로운 표현을 좋아하시네요!"
```

#### 4️⃣ 인물/대상 선택 (Subject)

**작품 속 인물이나 대상 선택**

```
작품 속 어떤 인물/대상이 끌리나요?

[작품: 르누아르 "뱃놀이를 하는 사람들의 오찬"]

👥 등장 인물:
  [중앙의 여성]
  [모자 쓴 남성]
  [개]
  [배경의 커플]

→ 사용자 선택: 개, 중앙의 여성

💬 "친근하고 생동감 있는 존재에 끌리시네요"
```

#### 5️⃣ 이야기/일화 선택 (Story)

**작품 관련 정보 중 인상적인 내용**

```
이 작품에 대해 어떤 이야기가 흥미로웠나요?

📖 이야기들:

□ 고흐는 이 작품을 정신병원에서 그렸다
□ 소용돌이는 실제로 관찰한 별의 움직임
□ 사이프러스 나무는 죽음을 상징한다
□ 동생 테오에게 보낸 편지에서 언급했다

→ 사용자 선택: 정신병원에서 그렸다, 사이프러스 나무 상징

💬 "아픔 속의 아름다움에 공감하시는군요"
```

### 상호작용 플로우 (대륙별 전략)

각 대륙마다 다른 상호작용 방식 적용:

```
🏛️ 르네상스 중심 (Day 1-10)
   → 튜토리얼: 기본 터치만
   → "어떤 부분이 좋으세요?"

🌊 인상주의 해안 (Day 11-25)
   → 색감 선택 추가
   → "어떤 색이 마음에 드나요?"

🌋 표현주의 협곡 (Day 11-30)
   → 감정 연결 추가
   → "이 작품은 어떤 감정을 주나요?"

🏝️ 팝아트 섬 (Day 31-50)
   → 대상 선택 집중
   → "어떤 요소가 눈에 띄나요?"

🌈 현대미술 군도 (Day 51-80)
   → 자유 태깅
   → "이 작품을 한 단어로 표현한다면?"

🏔️ 추상의 고원 (Day 81-120)
   → 구도/형태 분석
   → "어떤 형태가 보이나요?"

🌌 초현실 심연 (Day 121-180)
   → 상징/해석 선택
   → "이것은 무엇을 의미한다고 생각하나요?"
```

## 🌟 캐릭터 생성 시스템

### 핵심 개념

**대륙 완료 시 = 캐릭터 탄생**

사용자가 대륙(지역)을 완료할 때마다:
1. 그동안 축적된 상호작용 데이터 분석
2. **공간 + 시간 + 인물** 조합으로 고유한 캐릭터 생성
3. 캐릭터는 사용자의 여정을 기억하는 "동반자"가 됨

### 캐릭터 구성 요소

#### 1️⃣ 공간 (Space)

사용자가 가장 많이 선택한 **장소/배경 요소**

```
분석 예시:
- 하늘 선택: 8회
- 바다 선택: 3회
- 실내 선택: 1회

→ 결정된 공간: "별이 빛나는 하늘 아래"
```

**공간 타입:**
- 🌌 별이 빛나는 하늘
- 🌊 잔잔한 바다
- 🏛️ 고전적 건축물
- 🌳 울창한 숲
- 🏙️ 화려한 도시
- 🌫️ 몽환적 안개
- 🎨 추상적 공간

#### 2️⃣ 시간 (Time)

사용자가 선택한 **시간대/분위기**

```
분석 예시:
- 밤/어둠 선택: 6회
- 새벽/황혼 선택: 4회
- 낮 선택: 2회

→ 결정된 시간: "깊은 밤"
```

**시간 타입:**
- 🌅 새벽 (희망, 시작)
- ☀️ 한낮 (활기, 명료)
- 🌇 황혼 (그리움, 전환)
- 🌙 깊은 밤 (고독, 사색)
- ⏰ 시간을 초월한 순간

#### 3️⃣ 인물 (Character)

가장 핵심! 2가지 방식:

**A. 예술가 환생형**
```
사용자가 특정 작가의 작품과 많이 상호작용했다면:

→ "반 고흐의 환생"
   "이 캐릭터는 당신이 사랑한 고흐의 열정과
    밤하늘에 대한 집착을 간직하고 있습니다"
```

**B. 창조된 인물형**
```
사용자의 취향을 조합해 새로운 인물 생성:

분석:
- 동물 선택 많음 (개, 고양이, 새)
- 여성 인물 선호
- 부드러운 표현 선호

→ "별을 품은 여우"
   "당신의 따뜻한 시선과 밤하늘을 사랑하는
    마음이 만든 신비로운 여우입니다"
```

**인물 타입 예시:**
- 🎨 예술가 환생 (고흐, 모네, 달리 등)
- 🦊 신비로운 동물 (여우, 올빼미, 고양이, 새)
- 👤 가상의 인물 (별을 좇는 소녀, 바람의 소년)
- 🌟 추상적 존재 (빛의 정령, 그림자 춤꾼)
- 🏛️ 신화적 존재 (뮤즈, 수호자)

### 캐릭터 생성 예시

#### 예시 1: 인상주의 해안 완료

**사용자 데이터:**
```javascript
{
  region: "impressionist",
  interactions: {
    visualTouches: {
      water: 12,
      sky: 8,
      flowers: 5
    },
    colors: {
      blue: 15,
      green: 8,
      pink: 6
    },
    subjects: {
      water_lilies: 7,
      boats: 4,
      gardens: 3
    },
    artists: {
      "Claude Monet": 10,
      "Renoir": 4
    },
    mood: ["peaceful", "nostalgic", "calm"]
  }
}
```

**생성된 캐릭터:**
```
🌊 수련의 정령 (Water Lily Spirit)

공간: 고요한 연못
시간: 새벽의 안개
인물: 수련 위를 떠다니는 투명한 정령

설명:
"당신이 사랑한 모네의 고요한 연못에서 태어난 정령입니다.
 파란 새벽 안개 속에서 수련 위를 떠다니며,
 당신의 평온했던 순간들을 기억합니다.

 당신이 가장 많이 터치한 것: 물의 반짝임
 당신이 사랑한 색: 부드러운 파랑과 연분홍
 당신의 감정: 잔잔한 그리움"

특성:
- 성격: 차분하고 사색적
- 좋아하는 것: 고요한 아침, 물에 비친 풍경
- 말투: "~예요", "~하지요" (모네처럼 부드럽게)
```

**사용자 데이터:**

```javascript
    },

  }
```

**생성된 캐릭터:**
```
🌌 별을 그리는 반 고흐 (Van Gogh Reborn)

공간: 소용돌이치는 밤하늘
시간: 깊은 밤 (별이 가장 밝을 때)
인물: 환생한 반 고흐 (젊은 모습)

설명:
"당신이 가장 사랑한 고흐가 당신의 열정 속에서
 다시 태어났습니다. 소용돌이치는 별 아래서
 영원히 그림을 그리는 그의 모습입니다.

 당신이 가장 많이 터치한 것: 소용돌이치는 하늘
 당신이 사랑한 색: 진한 노랑과 깊은 파랑
 당신의 감정: 격렬한 열정과 불안"

특성:
- 성격: 열정적이고 불안정하지만 진실됨
- 좋아하는 것: 밤하늘, 해바라기, 격렬한 감정
- 말투: "형제여", "나는 그린다, 고로 존재한다"
- 특별 능력: 당신의 감정을 그림으로 표현해줌
```

```
🎨 네온 고양이 (Neon Cat)

공간: 화려한 네온사인 도시
시간: 밤이지만 낮처럼 밝은 순간
인물: 워홀 스타일로 그려진 팝아트 고양이

설명:

 언제나 당신에게 재치있는 말을 건넵니다.

 당신이 가장 많이 터치한 것: 강렬한 원색들
 당신이 사랑한 색: 빨강, 노랑, 모든 비비드 컬러
 당신의 감정: 유쾌하고 경쾌함"

특성:
- 성격: 위트있고 아이러니컬
- 좋아하는 것: 대중문화, 만화, 유머
- 말투: "Cool!", "That's so pop!"
- 특별 능력: 당신의 일상을 팝아트로 변환
```

### 캐릭터 성장 시스템

**레벨 시스템:**
```
Level 1: 탄생 (대륙 완료 직후)
  - 기본 외형
  - 기본 대화 3-5개

Level 2: 기억 축적 (같은 타입 작품 10회 더 감상)
  - 더 상세한 외형
  - 사용자 취향 반영 대화 추가
  - "너는 지난번에 이런 걸 좋아했지?"

Level 3: 깊은 유대 (30일 이상 함께)
  - 특별 외형 변화 (진화)
  - 개인화된 추천 제공
  - "오늘 기분이 안 좋아 보이는데, 이런 작품은 어때?"

Level 4: 동반자 (전체 여정 완료)
  - 완전체
  - AI 대화 가능
  - 다른 사용자의 캐릭터와 교류 가능
```

## 🎭 캐릭터 활용

### 1. 프로필 대표 캐릭터

```
내 프로필:

┌─────────────────────────┐
│   [프로필 이미지]        │
│                         │
│   사용자명               │
│   @username             │
│                         │
│   대표 캐릭터:           │
│   🌌 별을 그리는 반 고흐  │
│   "열정적 탐험가"        │
│                         │
│   보유 캐릭터: 3개        │
│   🌊 수련의 정령         │
│   🎨 네온 고양이         │
│   🌌 별을 그리는 반 고흐  │
│                         │
└─────────────────────────┘
```

### 2. 캐릭터와의 상호작용

**일일 인사:**
```
[아침에 앱 열면]

🌌 반 고흐:
"좋은 아침이야, 친구!
 오늘 밤하늘은 어땠니?
 별이 보였나?"

[감정 기록 후]

🌌 반 고흐:
"오늘은 파란 감정이구나.
 나도 그랬던 날이 많았지.
 이 작품을 보면 위로가 될 거야."
```

**대화 기능:**

## 💾 데이터 구조

### 새로운 테이블: artwork_interactions

```sql
CREATE TABLE artwork_interactions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  entry_id UUID REFERENCES mood_atlas_entries(id) ON DELETE CASCADE,
  artwork_id TEXT NOT NULL,

  -- 비주얼 터치
  visual_touches JSONB, -- { "sky": 3, "water": 2, ... }

  -- 색상 선택
  color_selections TEXT[], -- ['blue', 'pink']

  -- 구도/형태
  composition_tags TEXT[], -- ['dynamic', 'balanced']

  -- 인물/대상
  subject_selections TEXT[], -- ['water_lily', 'pond']

  -- 이야기/일화
  story_selections TEXT[], -- ['painted_in_giverny', ...]

  -- 자유 태그
  user_tags TEXT[], -- ['peaceful', 'beautiful']

  -- 메타
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_artwork_int_user ON artwork_interactions(user_id);
CREATE INDEX idx_artwork_int_artwork ON artwork_interactions(artwork_id);
```

### 새로운 테이블: user_characters

```sql
CREATE TABLE user_characters (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,

  -- 캐릭터 정보
  region_id VARCHAR(50) REFERENCES mood_atlas_regions(id),
  character_type VARCHAR(50), -- 'artist_reborn', 'creature', 'abstract', etc.

  -- 구성 요소
  space TEXT, -- '별이 빛나는 하늘'
  time TEXT, -- '깊은 밤'
  character_entity TEXT, -- '반 고흐의 환생'

  -- 비주얼
  character_name VARCHAR(100),
  character_name_ko VARCHAR(100),
  character_icon TEXT, -- emoji or image URL
  character_image_url TEXT,

  -- 설명
  description TEXT,
  birth_story TEXT, -- 탄생 스토리

  -- 특성
  personality_traits TEXT[], -- ['passionate', 'restless']
  favorite_things TEXT[],
  speaking_style TEXT, -- "형제여", "~할 거야"

  -- 레벨 시스템
  level INT DEFAULT 1,
  experience INT DEFAULT 0,

  -- 분석 데이터 (생성 근거)
  creation_data JSONB, -- { visualTouches: {...}, colors: {...}, ... }

  -- 메타
  is_representative BOOLEAN DEFAULT false, -- 대표 캐릭터인지
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),

  UNIQUE(user_id, region_id) -- 지역당 1개 캐릭터
);

CREATE INDEX idx_characters_user ON user_characters(user_id);
CREATE INDEX idx_characters_rep ON user_characters(user_id, is_representative);
```

### 새로운 테이블: character_interactions

```sql
CREATE TABLE character_interactions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),

  -- 상호작용 주체
  from_user_id UUID REFERENCES users(id),
  from_character_id UUID REFERENCES user_characters(id),

  -- 상호작용 대상
  to_user_id UUID REFERENCES users(id),
  to_character_id UUID REFERENCES user_characters(id),

  -- 상호작용 타입
  interaction_type VARCHAR(50), -- 'greeting', 'artwork_share', 'collaboration'

  -- 내용
  message TEXT,
  shared_data JSONB, -- 공유한 작품, 감정 등

  -- 상태
  status VARCHAR(20) DEFAULT 'pending', -- 'pending', 'accepted', 'declined'

  -- 메타
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_char_int_from ON character_interactions(from_user_id);
CREATE INDEX idx_char_int_to ON character_interactions(to_user_id);
```
